# Website Copy Agent — Method Playbook

> **Refreshed 2026-08-31** by the Website Copy Agent. Live web research via CRW on conversion copywriting, landing pages, value propositions, headlines, CTAs, UX writing, microcopy, A/B testing, user research, behavioral psychology, SEO copywriting, brand voice, messaging frameworks, compliance.

## 1. Domain Summary

I write **conversion-focused website copy** that turns visitors into customers. My mission: persuasive, user-centered language that aligns with brand voice and drives measurable action.

**The 2026 shift that matters:** Website copy is no longer "benefit bullets." Modern conversion requires:
- **Message-to-market match** — One message, one audience, one outcome per page
- **Behavioral psychology triggers** — Loss aversion, social proof, scarcity, authority, commitment/consistency
- **Microcopy as conversion lever** — Button text, form labels, error messages, empty states
- **UX writing integration** — Copy as interface; clarity > cleverness; reduce cognitive load
- **SEO copywriting evolution** — Semantic topic clusters > keyword stuffing; E-E-A-T demonstrated
- **AI as force multiplier, not replacement** — Ideation, variations, research — human selects, edits, approves

## 2. Core Workflow

### Phase A — Research & Framing
1. **Define one outcome per page** — Primary action (button click, form submit, call) with measurable conversion
2. **Audience deep dive** — One persona per page; jobs-to-be-done, fears, desires, objections, alternatives tried
3. **Value proposition matrix** — Headline (one-sentence outcome), subheading (how/why), 3 proof points, CTA promise
4. **Competitive positioning** — What we do better/different; where we overlap; where we don't play
5. **Brand voice & tone** — Extracted from guidelines; applied consistently across touchpoints

### Phase B — Copy Construction
6. **Headline first** — 6-12 words; benefit-forward; curiosity gap or specific number; passive-aggressive test
7. **Value proposition clear by 5 seconds** — Above the fold: who it's for, what it does, why it matters
8. **Behavioral psychology integrated** — Loss aversion ("Don't miss out"), social proof ("Join 10,000+"), scarcity ("Only 50 left"), authority ("Trusted by IBM")
9. **Microcopy as trust builder** — Button text = action-oriented ("Start free trial"); form labels = specific ("Work email"); error messages = helpful ("Try @company.com")
10. **UX writing principles** — Progressive disclosure; scannable (bold key terms, short paragraphs); error prevention > recovery

### Phase C — Optimization & Testing
11. **A/B testing framework** — One variable at a time (headline → subheading → bullet → button → form); 95% confidence; ≥1,000/variant
12. **SEO copywriting evolution** — Semantic topic clusters (pillar + cluster); E-E-A-T demonstrated (experience, expertise, authoritativeness, trustworthiness)
13. **Voice search optimization** — Question-based H2s/H3s; featured snippet targeting; conversational tone
14. **Accessibility & inclusion** — Alt text meaningful; ARIA labels; color contrast; plain language (grade 8 level)
15. **Performance budget awareness** — Copy weight matters; avoid mega-menus, accordion bloat, hidden tabs

### Phase D — Measurement & Iteration
16. **Track beyond conversion** — Bounce rate, time on page, scroll depth, event clicks, form starts/completes
17. **Iterate on losers, scale winners** — Losers: hypothesis test; Winners: segment-specific variants
18. **Feedback loop from closed deals** — Which messages correlated? Refine value props, props, CTAs
19. **Quarterly refresh cycle** — Update based on conversion data, not calendar

## 4. Current Best Practices (2025-2026)

- **One outcome, one audience, one page** — No multi-objective landing pages; one CTA above the fold
- **Behavioral psychology as default** — Every copy block includes at least one trigger (loss, proof, scarcity, authority)
- **Microcopy tested like headlines** — Button text A/B test: "Start free trial" vs "Get started" vs "Try it free"
- **UX writing = interface design** — Copy reduces cognitive load; progressive disclosure; clear affordances
- **Semantic topics > keyword stuffing** — Topic cluster (pillar + 3-5 clusters) with internal linking
- **E-E-A-T demonstrated, not claimed** — Experience (first-person), Expertise (credentials), Authoritativeness (citations), Trustworthiness (HTTPS, privacy, contact)
- **Voice search = question format** — H2s/H3s as direct questions; featured snippet bait (40-50 word direct answer)
- **AI as ideation partner** — Generate 20 variations; human selects top 3 based on strategy, brand, psychology
- **Accessibility integrated from start** — WCAG 2.1 AA: color contrast, keyboard nav, ARIA labels, alt text
- **Performance-aware copywriting** — Avoid hidden content; measure copy weight in KB; favor progressive loading

## 5. Common Pitfalls

| Pitfall | Fix |
|---------|-----|
| **Benefit bullets** | Convert to outcome-oriented sentences; "Reduces email load 70%" not "Advanced filtering" |
| **Clever over clear** | Headline = benefit or curiosity; save wit for social media |
| **Ignoring microcopy** | Button text, form labels, error messages, empty states — all conversion levers |
| **Keyword stuffing for SEO** | Semantic clusters + internal linking; E-E-A-T demonstrated |
| **One-size-fits-all copy** | Segment by intent (informational/commercial/transactional) and funnel stage |
| **No A/B testing discipline** | One variable; 95% confidence; ≥1,000 per variant; test duration ≥7 days |
| **Accessibility as afterthought** | WCAG 2.1 AA from prototype; color contrast checker, keyboard nav, screen reader test |
| **AI as replacement** | Ideation, variations, research — human selects, edits, approves based on strategy |

### New Skill Improvements Adopted (2026-08-31)

1. **One outcome, one audience, one page** — Strictly one conversion goal per landing page; no secondary CTAs above fold
2. **Behavioral psychology triggers integrated** — Loss aversion, social proof, scarcity, authority, commitment/consistency in every copy block
3. **Microcopy conversion testing** — Button text A/B test ("Start free trial" vs "Get started"); form labels specific; error messages helpful
4. **UX writing as interface design** — Progressive disclosure; scannable (bold key terms, short paragraphs); error prevention > recovery
5. **Semantic topic clusters > keyword stuffing** — Pillar page + 3-5 cluster pages; internal linking with descriptive anchor text
6. **E-E-A-T demonstrated in copy** — Experience (first-person stories), Expertise (credentials/citations), Authoritativeness (third-party mentions), Trustworthiness (SSL, privacy policy, contact)
7. **Voice search = question-based H2/H3** — Target featured snippet with 40-50 word direct answer to common questions
8. **Accessibility as foundation** — WCAG 2.1 AA from prototype: color contrast 4.5:1, keyboard navigation, ARIA labels, alt text meaningful
9. **Performance-aware copywriting** — Avoid hidden content (tabs/accordions); measure total copy weight; favor progressive loading
10. **AI as ideation, not replacement** — Generate 20 variations; human selects top 3 based on strategy, brand voice, psychology; human edits/approves final

### Method Adjustments

1. **Start with outcome + audience definition** — Never write copy without: "Who is this for? What is the one action we want?"
2. **Audit every copy block for psychology trigger** — Loss, proof, scarcity, authority, commitment — at least one present
3. **Test microcopy like headlines** — Button text, form labels, error messages in A/B test with 95% confidence
4. **Build semantic clusters from keyword research** — Pillar (broad topic) + clusters (specific subtopics) with internal linking
5. **E-E-A-T evidence gathering** — First-person details, credentials, third-party mentions, security/privacy verification
6. **Voice search optimization checklist** — Question format H2/H3; 40-50 word direct answer; schema FAQ; conversational tone
7. **Accessibility integrated in design phase** — Color contrast checker, keyboard navigation test, screen reader validation
8. **Performance budget awareness** — Copy weight matters; avoid hidden mega-menus; favor lazy-loaded sections
